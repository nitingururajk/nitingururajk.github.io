TokenFlow Lab: an LLM streaming simulator

A browser tool I built to see what different token rates look like in a chat response.

Apr 30, 2026·3 min read
Read post ↗

TokenFlow Lab streams text you provide at a chosen token rate. You can change the speed while it runs, compare tokenizers, and switch between even timing and small bursts. It simulates the output phase; it doesn't measure model performance or time to first token.

  • The TPS slider changes the stream as it runs.
  • The selected tokenizer determines the token count and boundaries.
  • Steady and realistic modes use different timing at the same target rate.

How prefix caching works (and how I broke it)

I put a timestamp ahead of a 6,000-token shared prompt and lost the cache hits. Moving it fixed the problem.

Mar 8, 2026·9 min read
Read post ↗

Prefix caching reuses KV state when requests start with the same tokens. I go through how vLLM, SGLang, OpenAI, and Anthropic handle it, then explain how a timestamp in my prompt builder stopped nearly 6,000 shared tokens from being reused.

  • A shared prefix needs identical tokens, including formatting.
  • Each serving system has its own cache controls and reuse rules.
  • Putting timestamps after the shared context restored my cache hits.
